# Daily Journal 📓

Веб-приложение для ведения ежедневных списков задач, заметок и закладок. Проект сочетает в себе бэкенд на Django (с асинхронными задачами Celery) и интерактивный интерфейс на чистом JavaScript (ES6+ Модули) с поддержкой горячих клавиш.

## ✨ Ключевые особенности

*   **Инлайн-управление задачами**: Создание и редактирование названий или комментариев к задачам прямо в таблице без перезагрузки страницы.
*   **Умные модальные окна**: Кастомные диалоги на базе Bootstrap 5 (в тёмных тонах) для подтверждения удаления и детального редактирования.
*   **Горячие клавиши**: Мгновенное создание новой задачи по нажатию клавиши `+` на любой раскладке клавиатуры.
*   **Гибридный API**: Наличие традиционного рендеринга страниц через Django Templates и готовых эндпоинтов REST API V1 под защитой JWT для интеграции с мобильными приложениями.
*   **Планировщик задач**: Интеграция с Celery и Celery Beat для автоматического расчета статусов или отправки уведомлений.
*   **Настройки уведомлений**: Пользователи могут управлять рассылкой уведомлений по email и Telegram через профиль. Чек-бокс Telegram активируется только при наличии привязанного ID чата.
*   **Современное управление зависимостями**: Проект полностью упакован с помощью Poetry.

---

## 🛠 Технологический стек

*   **Backend**: Django, Django REST Framework (DRF), SimpleJWT, Celery, Celery Beat.
*   **Frontend**: HTML5, CSS3, Bootstrap 5 (Dark Theme), Vanilla JavaScript (ES6 Modules).
*   **Пакетный менеджер**: Poetry.
*   **Database**: SQLite (для разработки) / PostgreSQL.

## 🚀 Быстрый старт

### 1. Настройка окружения и установка зависимостей
Убедитесь, что у вас установлен [Poetry](https://python-poetry.org).

```bash
# Клонирование репозитория
git clone https://github.com
cd Daily_Journal

# Установка виртуального окружения и всех зависимостей через Poetry
poetry install

# Активация виртуального окружения
poetry shell
```

### 2. Конфигурация переменных окружения
Создайте локальный файл `.env` на основе примера из `.env.sample`:
```bash
cp .env.sample .env
```
Заполните в `.env` секретный ключ Django, настройки базы данных и параметры подключения к брокеру для Celery (например, Redis).

### 3. Миграции и создание администратора
```bash
poetry run python manage.py migrate
poetry run python manage.py createsuperuser
```

### 4. Запуск проекта

**Запуск веб-сервера разработки:**
```bash
poetry run python manage.py runserver
```

**Запуск планировщика и воркера Celery (в отдельных терминалах):**
```bash
# Запуск воркера Celery
poetry run celery -A config worker --loglevel=info

# Запуск планировщика Celery Beat
poetry run celery -A config beat --loglevel=info
```

Приложение будет доступно по адресу: `http://127.0.0`

## 👤 Модель пользователя и настройки уведомлений

Проект использует кастомную модель пользователя `CustomUser` с расширенным функционалом:

### Основные поля модели CustomUser:
*   `username` — уникальное имя пользователя (используется для входа)
*   `email` — уникальный адрес электронной почты (обязательное поле)
*   `phone_number` — номер телефона (опционально)
*   `avatar` — аватар пользователя (опционально)
*   `tg_chat_id` — ID чата Telegram для интеграции с ботом (опционально)

### Настройки уведомлений:
*   `email_notifications` — флаг получения уведомлений по email (по умолчанию включен)
*   `telegram_notifications` — флаг получения уведомлений в Telegram (по умолчанию выключен)

**Особенности:**
*   Уведомления по email доступны всем пользователям, так как email обязателен при регистрации
*   Уведомления в Telegram доступны только пользователям с привязанным `tg_chat_id`
*   В форме редактирования профиля чек-бокс Telegram автоматически отключается, если у пользователя нет ID чата
*   Администратор может управлять настройками уведомлений через админ-панель Django

## 🗺 Маршрутизация проекта (URLs)

Проект использует строгое разделение на маршруты для классического веб-интерфейса (с рендерингом HTML-страниц) и REST API V1 для внешних интеграций.

### 🌐 Веб-интерфейс (HTML / Браузер)

Все маршруты веб-интерфейса возвращают HTML-страницы или JSON-ответы для инлайн-логики (AJAX/Fetch):

| URL | View-класс | Описание | Название (`name`) |
| :--- | :--- | :--- | :--- |
| `/daily/` | `TaskListView` | Главная страница со списком задач | `task_list` |
| `/daily/task/create/` | `TaskCreateView` | Инлайн-создание новой задачи | `task_create` |
| `/daily/task/update/` | `TaskUpdateView` | Инлайн-редактирование полей задачи | `task_update` |
| `/daily/task/delete/` | `TaskDeleteView` | Групповое/одиночное удаление задач | `task_delete` |
| `/daily/bookmark/add/` | `BookmarkCreateView` | Создание новой закладки через веб | `bookmark_create` |
| `/daily/bookmark/update/` | `BookmarkUpdateWebResponseView` | Редактирование закладки через веб | `bookmark_update` |

### 📱 REST API V1 (JSON)

Эндпоинты защищены авторизацией `Bearer <JWT_TOKEN>` в заголовке `Authorization`:

| Метод | URL | View-класс | Описание | Название (`name`) |
| :--- | :--- | :--- | :--- | :--- |
| **GET** | `/daily/api/v1/tasks/` | `TaskListAPIView` | Получить список всех задач | `task_list_api` |
| **GET / POST** | `/daily/api/v1/bookmarks/` | `BookmarkListCreateAPIView` | Просмотр (GET) и создание (POST) закладок | `bookmark_list_create_api` |
| **GET / PUT / PATCH / DELETE** | `/daily/api/v1/bookmarks/<int:pk>/` | `BookmarkUpdateExternalApiView` | Просмотр, обновление и удаление конкретной закладки | `bookmark_api` |

## 📂 Структура фронтенд-модулей JavaScript

Логика интерфейса распределена по изолированным файлам внутри папки `static/daily/js/`:
*   `create-task.js` — Инлайн-создание новой строки в таблице, валидация при сохранении и обработка горячей клавиши `+`.
*   `delete-tasks.js` — Групповое удаление выбранных задач с вызовом модального окна Bootstrap вместо системного `confirm`.
*   `editing-in-modal-window.js` — Логика открытия модального окна редактирования и отправка асинхронных fetch-запросов изменений на бэкенд.
*   `secondary-system-functions.js` — Утилиты для работы с куками (`getCookie`), автоматического пересчета номеров строк в таблице и обновления счетчиков.
*   `table-editor.js` (Главный файл) — Точка сборки, импортирует все модули и регистрирует их в объекте `window` для доступности из HTML.

## ⌨️ Горячие клавиши (Shortcuts)

*   `+` (или `+` на Numpad) — Мгновенно открывает строку инлайн-добавления новой задачи (работает, если фокус не находится в других полях ввода).
*   `Enter` — Сохранить задачу при инлайн-вводе.
*   `Escape` — Отменить инлайн-создание и скрыть временную строку.
